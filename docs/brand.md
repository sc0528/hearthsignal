# Hearthsignal brand

## Positioning

**Hearthsignal** is a calm, privacy-first daily briefing for people who run home labs.

Primary line: **Home lab health, interpreted.**

The voice is clear, capable, and reassuring. Explain impact before technical detail, recommend one practical next step, and avoid enterprise-monitoring jargon or alarmist language.

## Palette

| Token | Hex | Use |
|---|---|---|
| Ink navy | `#0B1D33` | Wordmark, headings, primary text |
| Ember coral | `#FF6B57` | Brand emphasis and signature moments |
| Signal blue | `#2563EB` | Links, controls, charts, signal arcs |
| Pine green | `#2E7D48` | Healthy state and outer signal arc |
| Warning amber | `#D98408` | Warning state only |
| Critical red | `#D9473F` | Critical state only |

Coral is the brand color; critical red remains a separate semantic color. Use true white backgrounds, ink navy text, thin cool-gray rules, and minimal shadow.

## Mark

The mark combines a small home with two signal arcs. Use [the SVG mark](../assets/hearthsignal-mark.svg) without changing its proportions or colors. Maintain clear space roughly equal to the coral doorway on every side. At very small sizes, use the mark without the wordmark.

## Naming

- Product: **Hearthsignal**
- Report: **Hearthsignal daily briefing**
- Individual findings: **signals** or **incidents**
- Avoid: “Healthsignal,” generic “monitoring dashboard,” and medical-health language
