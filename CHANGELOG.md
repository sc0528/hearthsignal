# Changelog

## 0.3.0 — Container appliance

- Made Docker Compose the recommended one-command installation.
- Added a scheduled browser-accessible report appliance with immediate first run.
- Added safe demo, zero-config Docker monitoring, and advanced live modes.
- Added last-good-report retention, health checks, and a status API.
- Added multi-architecture GHCR publishing for AMD64 and ARM64.
- Added container build, Compose validation, HTTP, and report smoke tests.

## 0.2.0 — Looking ahead

- Retains 30 local measurement snapshots and seven daily health scores.
- Forecasts near-term disk-capacity risks from observed growth.
- Adds Docker CPU, memory, restart-count, image, and health signals.
- Delivers a concise prioritized briefing through an optional Discord webhook.
- Adds a cross-platform setup doctor and safe configuration initializer.
- Introduces the report's “Looking ahead” section and refreshed public preview.

## 0.1.0 — Initial release

- Generates branded Markdown and HTML briefings.
- Collects opt-in Docker health, disk, backup freshness, and HTTP availability signals.
- Prioritizes incidents, explains impact, recommends actions, and tracks status changes.
